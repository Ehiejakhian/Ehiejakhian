## 🚀 Featured Projects

### 1. Aluminum Calcs

**Practical calculation and pricing tools for aluminium fabricators.**

Aluminum Calcs is a React application I'm developing to simplify everyday calculations, pricing, and quotation tasks in the aluminium fabrication industry.

Inspired by real-world workshop needs, the project combines my software development skills with my practical understanding of aluminium fabrication.

**Features**

* 🪟 **Glass Price Calculator:** Calculate glass prices using dimensions, thicknesses, glass types, and sheet pricing.
* 📏 **Stile Length Calculator:** Simplify aluminium profile length calculations.
* 📚 **Channel Reference:** Explore information about aluminium channels and their uses.
* 🧾 **Quotation Builder:** Prepare and manage customer quotations.
* 💾 **Local Storage:** Save supported application data in the browser.
* 📱 **Responsive Interface:** Designed for convenient use on mobile devices.

The project is actively evolving, with further improvements planned for material inventory, sales management, and backend integration.

**Tech stack:** React, JavaScript, Sass, Vite.

* 🌐 [Try Aluminum Calcs](https://aluminum-calcs.github.io/aluminum-calcs-new/)
* 💻 [Explore the source code](https://github.com/Aluminum-Calcs/aluminum-calcs-new)

**Earlier version:** The original application also includes an *Item Price Calc* for walk-in sales.

* [Explore the original version](https://aluminum-calcs.github.io/)
